# 🏋️ Gym Tracker TMA — Telegram Mini App & Бот для тренировок в зале

Полноценное приложение для силовых тренировок в тренажёрном зале, работающее прямо внутри **Telegram (Mini App / WebApp)** с поддержкой фонового **Telegram-бота на Aiogram 3**.

---

## ⚡ Ключевые возможности

1. **🎯 Генератор персональных программ тренировок**:
   - Автоматический расчёт сплита на основе веса тела, опыта тренировок (новичок / средний / опыт) и цели (гипертрофия, сила, рельеф).
   - Поддержка классических форматов:
     - **Full Body** (3 дня в неделю, акцент на все тело за раз)
     - **Upper / Lower** (4 дня в неделю, оптимальный баланс восстановления)
     - **Push / Pull / Legs** (3 дня в неделю, классика бодибилдинга)

2. **⏱ Интерактивный режим тренировки (Live Workout)**:
   - Быстрый ввод рабочих весов и повторений прямо во время подхода.
   - Подсказка предыдущего результата: *«Прошлый раз: 80 кг × 8»*, чтобы всегда знать, какой вес нужно преодолеть.
   - **Умный таймер отдыха**: автоматический запуск после завершения подхода (обратный отсчёт, звуковой сигнал и тактильная вибрация Telegram Haptic Feedback).
   - Празднование завершения тренировки с конфетти, подсчётом суммарного тоннажа (кг) и времени.

3. **📖 База упражнений (30+ базовых движений на русском языке)**:
   - Фильтрация по мышечным группам: *Грудь, Спина, Ноги, Плечи, Бицепс, Трицепс, Пресс*.
   - Инвентарь: *Штанга, Гантели, Блоки/Тренажёры, Собственный вес*.
   - Инструкции по технике выполнения.
   - Возможность добавлять свои собственные упражнения.

4. **📈 Прогресс и аналитика**:
   - Расчёт **1RM (одноповторного максимума)** по проверенной формуле Эпли:
     $$1RM = Weight \times \left(1 + \frac{Reps}{30}\right)$$
   - Карточки рекордов для основных движений (Жим лёжа, Приседания, Становая тяга и др.).
   - Суммарный тоннаж тренировок, количество сетов и история занятий.

5. **🤖 Telegram-бот (Aiogram 3)**:
   - Установка постоянной кнопки **«💪 Открыть зал»** (`MenuButtonWebApp`) в меню чата Telegram.
   - Команды: `/start`, `/workout`, `/help`.

---

## 🛠 Технологический стек

- **Backend**: Python 3.14, FastAPI, SQLAlchemy 2.0 (async), aiosqlite, Aiogram 3.4, Pydantic v2.
- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS (высококонтрастная тёмная спортивная тема).
- **Интеграции**: Telegram WebApp SDK, Web Audio API (звуковой таймер без внешних файлов), Canvas Confetti.

## 🚀 Быстрый старт

### Вариант 1: Запуск единого сервера (Production-режим)
В этом режиме FastAPI на порту `8000` отдаёт и REST API, и собранный React интерфейс, и запускает бота:

```bash
# 1. Запуск через готовый скрипт:
.\start_server.bat

# Или вручную:
cd backend
.\.venv\Scripts\python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```
После запуска откройте в браузере: **`http://localhost:8000`**

---

### Вариант 2: Режим разработки (Dev-режим с горячей перезагрузкой)

Запустите бэкенд и фронтенд параллельно:

**Терминал 1 (Бэкенд):**
```bash
cd backend
.\.venv\Scripts\python -m uvicorn app.main:app --reload --port 8000
```

**Терминал 2 (Фронтенд):**
```bash
cd frontend
npm run dev
```
Фронтенд откроется по адресу: **`http://localhost:5173`** (все запросы к `/api` автоматически проксируются на бэкенд `8000`).

## 📱 Подключение к реальному Telegram

1. Откройте в Telegram официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду `/newbot`, укажите имя и username для вашего бота.
3. Скопируйте полученный HTTP API токен (например: `7123456789:AAH...`).
4. Откройте файл `backend/.env` и вставьте ваш токен:
   ```env
   BOT_TOKEN=7123456789:AAH...
   ```
5. Для работы Mini App внутри Telegram требуется HTTPS-ссылка. Для локальной разработки используйте [ngrok](https://ngrok.com) или [localtunnel](https://localtunnel.github.io/www/):
   ```bash
   ngrok http 8000
   ```
   Скопируйте полученную ссылку (например, `https://abcd-1234.ngrok-free.app`) и укажите её:
   - В `backend/.env` в поле `WEBAPP_URL=https://abcd-1234.ngrok-free.app`
   - В @BotFather через команду `/setmenubutton` -> выберите вашего бота -> укажите URL.
6. Перезапустите бэкенд — теперь бот активен, и в чате с ним появится кнопка открытия Mini App!

## 🧪 Тестирование

Для запуска автоматических тестов API, генератора программ и формул 1RM:

```bash
cd backend
.\.venv\Scripts\pytest -v
```
Все 5 тестов проверяют:
- Работоспособность сервера (`/health`)
- Каталог упражнений и базу данных
- Алгоритм генерации программ
- Расчёт формулы Эпли 1RM
- Полный цикл тренировки (старт, запись подходов, подсчёт тоннажа, аналитика)
